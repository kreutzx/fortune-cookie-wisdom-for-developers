## The line

> He who merges on Friday at 5 p.m. will debug on Sunday at dawn.

## About

A one-line fortune-cookie wisdom for developers: merging late on a Friday invites a dawn debugging session on Sunday. The entrypoint (`main.py`) writes this line, plus a trailing newline, to `/output/entry.txt`.
